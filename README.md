# 원큐노트

> 뭘 살지 고르는 것부터 언제 팔지까지, 첫 투자의 기준을 손님이 직접 세우는 서비스

제1회 하나증권 청년 금융 아이디어 공모전(주제 01 · 새로운 손님서비스 발굴) 제안 아이디어를 휴대폰에서 직접 눌러볼 수 있게 만든 프로토타입입니다.

**체험하기 → https://mellene.github.io/onequ-note/**

휴대폰으로 열면 앱처럼 전체 화면으로, PC로 열면 왼쪽에 시나리오와 QR 코드, 오른쪽에 폰 화면이 나옵니다.

> 공모전 제안용 시안이며 실제 하나증권 서비스가 아닙니다. 화면 속 결제 횟수·수익률·AI 브리핑 문구는 예시입니다.

---

## 왜 만들었나

처음 투자하는 손님의 어려움은 정보 부족이 아니라, **판단 기준을 연습할 기회 없이 곧바로 실전 자금을 넣는 구조**에서 비롯된다고 봤습니다. 제가 처음 투자할 때도 무엇을 살지, 언제 사고팔지, 뉴스를 믿어도 되는지, 레버리지·인버스가 어떻게 움직이는지 모른 채 돈부터 넣어야 했습니다.

이 문제는 실제 손실로도 확인됩니다.

- 2026년 5월 출시된 단일종목 레버리지 ETF의 개인 손실은 8월 14일까지 약 6.3조 원, 계좌당 평균 약 1,156만 원 (금융감독원 집계)
- 출시부터 7월 14일까지 SK하이닉스 본주는 -6.77%, 레버리지 ETF 7종 평균은 -33.79% (약 5배)
- 고위험 ETF 지식 정답률 평균 53.8%, 2030세대가 타 연령보다 낮음 (한국금융소비자보호재단)

## 체험 흐름

사회초년생 '김하나(26)'가 되어 첫 투자를 따라가고, 마지막에는 평소 종목 화면에서 쓰는 '관계 보기'까지 확인합니다. 각 화면 위의 안내 바가 다음에 누를 곳을 알려줍니다.

| 단계 | 화면 | 해결하는 고충 |
| --- | --- | --- |
| 1 | **월급날** · 하나은행 급여일에 원큐노트 시작 제안 | 진입 계기 |
| 2 | **시작점 고르기** · 직접 검색, 관심 분야, 하나카드 결제 내역(동의 시)에서 아는 회사 선택 | 무엇을 살지 모름 |
| 3 | **종목 관계 지도** · 우선주·관련 우량주·반도체 ETF는 안쪽, 단일종목 레버리지·인버스·지수 곱버스는 바깥쪽에 위험도 순 배치. 누르면 실제 상품 목록과 구조 설명이 열림. '목록으로 보기'에서는 관련주 10종(같은 업종·장비·소재·부품·HBM 장비)을 관계별로 확인 | 관련 상품을 모름 |
| 4 | **개념 시뮬레이터** · 주가 변동을 슬라이더로 움직여 1배·2배·인버스 결과 비교 | 레버리지·인버스 개념 |
| 5 | **나의 기준 카드** · 산 이유, 목표 수익률, 손절선, 투자 금액을 직접 정하고 매수 | 매수·매도 기준 없음 |
| 6 | **기준 알림** · 손절선에 가까워지면 처음 산 이유를 다시 보여주고 판단을 묻기 | 뉴스 신뢰, 감정적 매매 |
| 7 | **월간 돌아보기** · 기준을 지킨 횟수와 산 이유별 결과 확인 | 투자습관 형성 |
| 8 | **평소에도 관계 보기** · 원큐노트 밖에서도 종목 상세 화면의 '관계 보기' 탭에서 공급망(소재→장비→기업), 경쟁사, 협력업체, 계열사, 관련 ETF·파생상품을 관계별로 확인 | 처음 보는 기업의 연결 관계를 모름 |

직접 해볼 수 있는 것: 시작점 탭 전환, 시뮬레이터 슬라이더, 기준 카드의 이유·수익률·손절선·금액 선택. 기준 카드에서 고른 값과 메모는 '3주 뒤' 알림 화면에 그대로 다시 나옵니다.

## 설계 원칙

- **추천하지 않습니다.** 정보를 정리해 보여주고, 무엇을 살지와 기준은 손님이 직접 정합니다.
- **기존 기능을 살립니다.** 하나증권V의 AI 브리핑을 알림에 연결하고, 성향 기반 ETF MBTI와는 겹치지 않게 했습니다.
- **하나금융이라서 가능한 입구.** 하나은행 급여일, 하나카드 결제 내역을 동의한 손님에게만 시작점으로 씁니다. 동의하지 않아도 모든 기능을 쓸 수 있습니다.

## 기술

- HTML·CSS·JavaScript 한 파일 (`index.html`), 빌드 과정 없음
- 화면 전환은 주소의 `#`으로 처리 (`#map`, `#sim` 등으로 특정 화면 바로 열기 가능)
- QR 코드: [qrcodejs](https://github.com/davidshimjs/qrcodejs) — 페이지가 올라간 주소를 읽어 자동 생성
- 글꼴: Noto Sans KR (Google Fonts)
